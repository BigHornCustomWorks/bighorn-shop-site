# Big Horn Custom Works

Public shop site for Big Horn Custom Works LLC (Sheridan, Wyoming). This is **not** Shopify.

- Catalog checkout: Stripe Checkout (test mode until live keys are set)
- Custom jobs: quote form → Master Control inbox (and email if Resend is configured)
- Repair Status is a text link only — not a catalog product

## Master Control

Open `/master`. Password is `MASTER_CONTROL_PASSWORD`.

Clint can add/edit/hide/reorder products, change copy, photos, prices, variants, and shipping notes without a deploy.

## Env

See `.env.example`. Preview URL first — do not point `bighorncustomworks.com` until Clint says the preview is good.
